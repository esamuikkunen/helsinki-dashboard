# Helsinki Home Dashboard

Map of Helsinki postal-code areas and buildings with dwelling prices, rents, census figures, schools, lukiot, transit and noise.

Open it: https://esamuikkunen.github.io/helsinki-dashboard/

Data: Statistics Finland (Paavo, dwelling prices, rents; CC BY 4.0), City of Helsinki building register and noise survey (CC BY 4.0), © OpenStreetMap contributors (ODbL), väestökello.fi, s2koulut.xyz, kouluhaku.fi, yhteishaku.app. Building values are rough estimates, not valuations.
